# Public Boundary

This repository is the public discipline and research mirror for Agent
Responsibility Engineering. It is meant to be readable, citable, and safe to
share.

It is not the full ARE platform.

## Public In This Repo

This repository may include:

- ARE tenets and discipline language
- public STAMP/STPA paper artifacts
- public STPA mirror files
- diagrams and explanatory models
- public-safe evidence summaries
- validation-tier definitions
- citation metadata
- contribution and security guidance

## Not Public In This Repo

This repository must not include:

- private ARE platform source code
- Command Center source or visual RAG internals
- BYOPolicy commercial UX or private policy bodies
- S2-S6 adaptive platform internals
- governance-strata internals
- private proof packets or raw gate logs
- raw payloads, headers, credentials, signatures, or tokens
- protected evidence bodies
- customer or employer confidential material

## Related Surfaces

| Surface | Public? | Relationship |
|---|---:|---|
| AgentResponsibilityEngineering | Yes | Discipline, paper, STPA mirror, public evidence summaries |
| ARE Foundation | Yes | S0/S1 runnable foundation for identity, scoped authority, policy, and proof basics |
| Commercial ARE platform | No | Full Command Center, visual proof, BYOPolicy, Live Pulse, S2-S6, client/operator UX |
| Governance-strata | No | Higher-risk transition governance and orchestration internals |

## How To Explain It

Use this:

> AgentResponsibilityEngineering is the public discipline and research repo. ARE
> Foundation is the public runnable S0/S1 foundation. The full ARE platform adds
> commercial operator workflows, visual proof, BYOPolicy, observability,
> governance-strata, and adaptive higher-stage controls.

Avoid implying:

- this repo is a production runtime
- the paper is a certification
- all implementation evidence is public
- governance-strata internals are bundled here
- private proof packets are hidden because evidence is weak

The boundary exists to keep public research useful while protecting private
implementation, client safety, and sensitive proof material.
